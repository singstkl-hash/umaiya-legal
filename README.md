# Umaiya — pages légales

Pages publiques d'[Umaiya 旨屋](https://github.com), l'application pour
apprendre le japonais en cuisinant.

- `index.html` — politique de confidentialité
- `conditions-utilisation.html` — conditions générales d'utilisation
- `assistance/` — assistance et questions fréquentes
- `en/` — les trois pages en anglais (`index.html`, `terms.html`, `support/`),
  reliées aux pages françaises par un lien en tête de page

Ce dépôt ne contient **que** ces pages. Le code de l'application reste privé.

## Publication

Servi par GitHub Pages depuis la branche `main`, dossier racine.
Réglage : **Settings → Pages → Source : Deploy from a branch → main / (root)**.

## Mise à jour

La version de référence de chaque page est maintenue en Markdown dans le dépôt
de l'application : `docs/politique-confidentialite.md` pour `index.html`,
`docs/conditions-utilisation.md` pour `conditions-utilisation.html`,
`docs/privacy-policy.md` et `docs/terms-of-use.md` pour `en/`. En cas de
modification, reporter le texte ici et actualiser la date de mise à jour
affichée en haut de la page HTML correspondante.
